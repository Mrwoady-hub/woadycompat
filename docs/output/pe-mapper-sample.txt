------------------------------------------------------------------------
  STEP 5 — Apply relocations (if base address changed)
------------------------------------------------------------------------
  .reloc section present : yes
  Relocations stripped   : no

  WHY: If the image was not loaded at its preferred image base,
  every absolute address embedded in the code is wrong.  The .reloc
  section lists every such address so the loader can add a delta
  (actual_base − preferred_base) to each one.  DLLs almost always
  need this; many EXEs are stripped (no .reloc) and must load at base.

  STEP 6 — Hand off to the entry point
------------------------------------------------------------------------
  Entry point RVA : 0x000013e0
  Entry point VA  : 0x00000000004013e0  (image_base + RVA)

  For an EXE the loader jumps to this address.  On Windows that lands
  in the CRT startup stub which calls WinMain / main.
  Wine redirects execution here after mapping all DLLs.
